## 3. 下一步的三条路（需要你选）

### 路线 A：补齐实时盘口，让 8810 能完全替代 8800 看盘

要接常驻行情通道（QMT tick 或 eltdx 快照），然后做分时图、五档、成交明细。工作量最大，但做完「看盘」这件事就彻底不用开 8800 了。

### 路线 B：先切流，实时盘口留在 8800

现在这六张卡已经覆盖「复盘 + 板块轮动 + 自选跟踪 + 作战表查看」。切流后日常先看 8810，要盘中细节回 8800。风险最小，今晚 19:20 自检跑完就能切。

### 路线 C：先补选股/复盘页

这两页是「盘后工作」的主入口。但它们的逻辑都还没评估过，得先看旧端实现，工作量未知。

## 4. 我的建议

**先走 B，再走 A。**

理由：这六张卡的双跑已经做到 31/31、全量 225,986 字段零差异，是**目前唯一被充分验证过的部分**。先把它变成日常入口，你就有了真实使用反馈——用一周后你自己会知道「分时图到底有多需要」，比现在猜准。

同时并行评估 A 的成本：分时图需要什么数据、QMT 与 eltdx 哪条路更稳、要不要动常驻进程。这些我可以在你切流后先摸底，不动代码。
