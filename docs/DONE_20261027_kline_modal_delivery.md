## 4. 边界与未做（不许读成「旧版全量等价」）

1. **真实生产下单 / 撤单 / 条件单落库未实测**：所有写路径只在隔离 fetch 桩与 CDP DOM 桩里跑过。
2. **没有发过生产 POST**：嗅嗅拦截器 + CDP 网络记录双重证据。
3. **砖形图未实现**（有旧版公式但缺对拍样本，按「不伪造」不做，界面无入口）。
4. 主图 MA / BOLL / 缠论、副图窗高拖拽与双模板：**不在本次范围**。
5. 因此**不能称「旧版 504KB 图库全量等价」**：本次覆盖的是弹窗交互、周期、副图与纸面交易链，主图库的其余能力未搬。
6. **版本串需随前端改动手动 bump**；已打开的页面不会自动刷新模块（浏览器固有行为），刷新/重开才拿到同一版本的一套。
7. 静态文件无 `Cache-Control`（在 core/静态服务层，超出白名单）——靠 `?v=` 换 URL 生效，不是强一致缓存协议。

- 带**伪造旧 ETag** 请求仍返回 **200**（未错误命中 304 旧体）。
