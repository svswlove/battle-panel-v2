## 2. 今天做的关键决策（别再推翻重来）

### 2.1 迁移路线：复用旧前端，换数据源

**不是**重做一套新前端。做法是把旧前端托管到 8810，只改 `shell.html` 两处（`ENGINE` 同源、`PAGE_BASE` 指向 `/legacy/`），
其余前端文件**零拷贝**（直接挂载 `engine/web`，旧仓一改立即生效）。

### 2.2 数据源对齐旧端，不是“能跑就行”

- **个股 K 线走 eltdx**（`adjust="qfq"`），实测 120 根与旧端**零差异**；`track_pool.db` 已从 kline 插件移除
- 板块指数仍走 vipdoc（旧端口径）
- `track_pool.db` **保留**（旧系统核心库，`track_db`/`track_data`/`qmt_close_collector` 在用），sector 仍读它（全市场两日收盘：查库 0.2s vs eltdx 批量 10s）

### 2.3 写通道：从「零写入」改成「受控写」

**这是今天最重要的架构变更，必须保留**：

```
ctx.panel_write(name, payload)
  → 白名单双闸（manifest.data.write + paths.WRITABLE_PANEL）
  → 备份到 data/panel_v2/backups/<name>/<时间戳>.json
  → 原子替换（tmp → os.replace）
  → 审计日志 audit.log
```

当前白名单只有 `watchlist`。

**代价**：回退不再是“停 8810 就原样恢复”。要额外从备份恢复被写过的文件。
见 `docs/CUTOVER_RUNBOOK.md §3.3` 和 `docs/CONTRACT.md §4.2`。

### 2.4 根路径挂载

兼容插件在 manifest 写 `backend.mount = "root"` → 路由挂到 `/api`（不是 `/api/p/<id>`）。
两个插件抢同一路径**启动即报错**。实现在 `app/core/main.py`，测试在 `app/tests/test_mount_contract.py`。

## 6. 已知坑（省得再踩）

| 坑 | 说明 |
|---|---|
| **DSHana 没有 shell** | 派单必须写明“只写代码 + 标未运行验证”，否则它浪费时间试 curl/pytest，或自报“全绿” |
| **DSHana 的 reply 用 taskId 会报错** | 改用 `sessionId`（`session-<uuid>`）可通 |
| **改含中文的源码不能用 PowerShell `Get-Content\|Set-Content`** | PS5.1 按 ANSI 读、UTF-8 写 → 中文注释全乱码。用 `edit` 工具或 Python 显式 utf-8 |
| **`Get-Content` 读 UTF-8 文件显示乱码** | 只是控制台显示问题，用 Python 读正常 |
| **eltdx `bars.get` 单次 `count>800` 返回 None** | 翻页必须用 `start` 偏移 |
| **eltdx 1m 的 `count` 是跨日“最近 N 根”** | 不是“当日全量”，要按末根日期过滤 |
| **`trades.today(start=N)`：start 越大时间越早** | 见 §3 #1 |
| **`task.page("p2")` 不存在** | 用 `await task.newPage()`（无参数） |
| **窗口最小化时不能截图** | `Error: Cannot capture a screenshot while the window is minimized` |
