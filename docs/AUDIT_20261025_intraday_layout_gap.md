# 盘中卡排版差异审计（v2 盘中卡 vs 旧页 8800 盘中 Tab）

2026-10-25 · 01 · 本单（v2 盘中卡照 8800 旧页补齐）第 1 步交付物
判据来源：真实浏览器（headless Chromium）+ 真实鼠标事件，非静态估算。

> **结论先行**：主人说的「排版没按旧版、少了很多图表」是**同一件事**——
> 旧页盘中页是「**三处多栏 + 一处两栏等宽等高**」的排版，v2 全部拍成了**单列全宽**；
> 图表缺 3 张（日内演化 2 张 + 成交额分时 1 张），而**分栏一塌，这 3 张图就没有落脚处**，
> 所以「排版」和「图表」必须一起修，顺序是**先补栏、再补图**。
> 另有 3 个 v2 独有的块（AMV / 轨迹摘要 / 盘中脉冲）旧页盘中没有，占位与块序都要主人拍板。

### 2.3 块序差异（这一条最影响「像不像旧页」）

旧页（`renderIntraday` 4710-4731，实测 DOM 顺序逐条对上）：

```
src → 冰点监控 → sess-line → 实时行情 → [两市成交额 ｜ 板块轮动] → 日内演化
    → 板块与个股研究 → 持仓实时状态 → details 审计明细(折叠)
```

v2（实测 14 个子节点）：

```
it-top → 冰点 → sess-line → 实时行情 → AMV → 广度880 → 成交额对比 → 板块轮动
       → 研究 → 轨迹摘要 → 盘中脉冲 → 审计明细 → it-src
```

**差异点**：

1. **`top-split` 塌了**：旧页「成交额 ｜ 板块轮动」是**同一行两栏、等高缝合**；
   v2 两块各自全宽、之间还夹了 AMV 与广度 880 两个块。
2. **`日内演化` 整块缺失**：旧页在板块轮动正下方（y=1449，442.7 高）。
3. **广度 880 从窄栏小卡升成全宽大块**（内容同、位置全变）。
4. **AMV / 轨迹摘要 / 盘中脉冲** 三块旧页盘中不存在，把旧页 8 个块插成了 13 个。

## 七、未验证 / 已知边界
