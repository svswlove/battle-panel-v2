# 2026-10-30 副图柱体统一到 70% 不透明度

> 来源：主人「柱体调整到70%亮度」，承接两条标注（`N20261030-005524-56` / `-57`）——
> 位置已核实为 K 线弹窗的成交额副图与主力资金副图。

## 1. 改前现状（生产文件 `engine/web/kline_lc.js`）

| 柱体 | 改前 | 说明 |
|---|---|---|
| 成交额·阴线柱 | `hexToRgba(pal.down, 0.55)` | 2026-10-28「与 K 线一致」时定：阳线空心（由 `drawHollow` 描边）、阴线实心 55% |
| 成交额·阳线柱 | `rgba(0,0,0,0)` | 透明，靠描边成空心——本次不动 |
| 主力资金·正柱 | `pal.up` 实色 100% | — |
| 主力资金·负柱 | `pal.down` 实色 100% | — |

两个窗口径不一致：一边 55%、一边 100%。

## 2. 改法

新增常量 `var SUB_BAR_ALPHA = 0.7;`（`palette()` 上方），两处 hist 的柱色统一走它：

- 成交额阴线柱：`hexToRgba(pal.down, SUB_BAR_ALPHA)`（0.55 → 0.7）
- 主力资金柱：`hexToRgba(v >= 0 ? pal.up : pal.down, SUB_BAR_ALPHA)`（100% → 70%）

「亮度 70%」按**不透明度 0.7** 实现：深色底上柱色与背景按 7:3 混合，视觉等价于亮度打七折，
且与两条标注原话「透明度调到 70%」一致。

## 3. 没动的地方（有意的）

- **空心柱描边**（`drawHollow`）：描边是线不是柱体，保持实色，否则空心柱几乎看不见。
- **主买细柱**（`drawMfThin`，亮黄）：它是区分主买的标记，只有 0.34 柱宽，降透明度会消失。
- **分时模式成交量柱**（`buildSubsIntraday`）：另一套副图，主人点名的两处都在日线；要一起改说一声。
- **主图 K 线蜡烛**：不是「柱体」，未动。
