# thermometer 插件 · 情绪温度计

一屏看完：**从读数到动作**。八段固定顺序（照主人给的参考形态组织，数据换成我们自己的口径）：

| # | 段 | 内容 |
|---|---|---|
| ① | 四格 KPI | 情绪指数 / 恐慌广度 / 上涨·下跌家数 / 成交额，每格带前一日对比 |
| ② | 温度计 | 0–100 刻度条 + 当前位置指针 + 五档标签（亢奋/偏热/中性/偏冷/冰点）+ 一句状态说明 |
| ③ | 今日盘面指标 | 12 格，每格「原始值 + 分位」；晋级率标明样本是否足够 |
| ③b | **四维拆解** | 广度 / 接力 / 资金 / 位置：各 0–100、独立不合成，带进度条 + 方向标签 + 一句说明 |
| ④ | 今日 vs 昨日 | 8 行对比表（含差值与方向色） |
| ⑤ | 趋势确认图 | 近 58 个交易日：情绪指数线 + 恐慌广度线 + 上涨家数柱，**标恐慌口径断点** |
| ⑥ | 预警区 | 按今日读数逐条判：触发了什么、为什么 |
| ⑦ | 现在该做什么 | 三态动作：不加仓 / 做结构 / 等信号（规则写在页面上） |
| ⑧ | 信号→动作表 | 5 条触发条件；胜率与次数一律「样本不足（58 日）」 |

## 本插件不产数（最重要的一条）

| 读数 | owner | 页面怎么拿 |
|---|---|---|
| 情绪指数 / 六因子 / 涨停·跌停·炸板率·最高板·连板·封板率·晋级率 / 涨跌家数 / stage | `emotion` 插件（口径 v1.1） | 前端 `ctx.api.get('/api/p/emotion/payload?history_days=60')` |
| 恐慌广度 / 四项（含跌停占比、上涨占比、全A中位、量能）/ 成交额 | core `panic_calc` → 旧仓 `engine/collectors/panic_breadth.py`（250 日滚动分位） | 前端 `ctx.api.get('/api/panic')` |
| 恐慌口径断点日期 + 序列库行数 | **本插件** `/meta`（只读 `data/panel/panic_breadth.json`） | 前端 `ctx.api.get('/meta')` |
| 四维分数与子项分位 | **本插件** `/dims`（读 `sentiment` 收盘行 + `kline` 位置序列，后端算分） | 前端把上游事实（晋级率/全A中位/量能）作查询参数透传 |

- **不重算情绪分、不重算恐慌广度**：两个口径的唯一源在各自 owner 那里，本插件没有它们的公式。
- **不跨插件 import**（CONTRACT §8）：`emotion` 与 `/api/panic` 都按 HTTP 接口消费，插件之间零耦合。
- **数据库只读、只读自己需要的两处**：`manifest.data.read = ["track_pool.db"]`，走 `ctx.db_read`（`PRAGMA query_only=ON`）：
  `sentiment`（只取 `ts='close'`）与 `kline`（只取位置维度那一个代码）。**不写任何生产文件**。
- 文件访问另一处：`ctx.panel_json("panic_breadth")`，只用来数行与看断点，不重算分位。
- **上游旧行不冒今日**：`/api/panic` 在非交易时段（开盘前、零点后）按设计回落到库内最后一行（`mode=closed`）。
  页面把它的 `trade_date` 与情绪侧数据日比对，不等就把恐慌侧全部标「缺」并在预警区写明——不拿旧行充今日；
  四维里的全A中位/量能因此也不透传。
- 前端只做展示层派生：格子里的小字分位（见下）与三态动作判定，两者都在页面上写明口径。

## 两条口径判断（页面、README、代码注释三处一致）

### 1. 恐慌广度是「低值 = 恐慌」，与情绪指数**同向**

旧仓 `panic_score()` 的注释是「0–100，低值 = 恐慌」，`state_of()` 的标签是
`<10 极冰 / 10–25 冰点 / 25–75 正常 / 75–90 乐观 / >90 过热`。也就是说：
**值越高越热**，与 emotions 的六因子分方向一致（10-22 情绪 14.56 / 恐慌 5.6；10-23 情绪 86.06 / 恐慌 90.6）。

任务书原稿把两者当成「方向相反」，与实际口径不符。页面按实际口径画：图例逐条写
「同向：越高越热、低值=恐慌」，并把「两个口径同日都落冰点 = 方向一致」写进动作依据，
不让人把它读成反向对冲。

### 2. 恐慌口径断点：2026-10-29 起四项（此前 1264 行是三项）

- 三项口径 = 跌停占比 / 上涨占比 / 全A中位；四项 = 前三项 + 量能（当日全天额 ÷ 昨日全天额）。
- 今日（10-29）四项现算 23.1，是完全不同分母下的读数，**不能与 10-23 的 90.6 直接比**。
- 图上处理：断点竖线 + 「口径切换 10-29」标注；历史段虚线、今日单点实心；
  两个口径之间**不连线**（`splitSegments()` 在断点日强制断开），图注写明不直接比较。
- 断点日期只有一处写死：`backend.CALIBER_BREAK`。`/meta` 同时回 `store.four_item_first`
  与 `drift`：哪天序列库真落了四项行、且首个四项行与常量不一致，会显式报漂移，不静默改口。

## 四维拆解（2026-10-29 加）

四维是**新指标**（owner = 本插件），用来把「一维总分」摊开看广度/接力/资金/位置各处在什么位置。
**不替代、不重算**情绪总分（仍在 emotion，口径 v1.1），四维之间**也不加权合成**。

| 维度 | 子项（每项 0–100 分位，方向统一为越高越热） | 方向处理 | 窗口 |
|---|---|---|---|
| 广度 | 上涨家数占比 / 涨停家数 / 跌停家数 / 全A中位 | 跌停取 `1−分位` | sentiment 58 日 + panic 250 日（中位） |
| 接力 | 最高板 / 连板数 / 晋级率 / 炸板率 | 炸板率取 `1−分位` | sentiment 58 日 |
| 资金 | 量能 / **主力资金（880008 占成交）** / **龙虎榜净买额** / 北向（停披露） | 直用分位 | panic 250 日 + 龙虎榜 35 日 + **主力资金 L2 序列 250 日分位** |
| 位置 | 距 MA20 / 距 MA60 / 距 250 日高（**880008 全A**） | 直用分位 | 880008 250 日分位（序列 3,650 根） |

- **窗口是「要求 250、用现有样本」**：`sentiment` 只有 58 个 `ts='close'` 行，所以情绪侧子项实际是 58 日基，
  返回里每项带 `base` 字段（页面上写「58 日」），不把 58 说成 250。全A中位与量能只有 panic 的 250 日分位（唯一源，透传）。
- **晋级率样本保护**：分母（昨日 2 板家数）由 emotion 透传，<10 只 → 不参与（`denominator` 字段留证）。
- **炸板率只出分位、不出绝对值**：库内自算偏高约 7.5pp，绝对值不可比。
- **两融已整项移出资金维度（2026-10-30）**：两融是**逐票数据、无市场级接口**（880008 的 F10 `rzrq`：`table0` 空表、
  `table1` 全 None，已实测）；用 300 只沪深300 成分股聚合需 **2.6 分钟**，换来的边际信息量不抵成本 ⇒ 移出。
  相关代码 / 常量 / 页面提示 / 盘后链步骤已清掉；`tools/margin_balance_daily.py` 保留文件但标「已退役、不得再挂」。
- **北向 = 官方停披露**：日频金额自 2024-08 全 null，只剩季度持仓 → 资金维度显式列一项「缺」，不做日频。
- **主力资金（880008 占成交）= L2 历史序列 + 250 日分位（2026-11-06 加）**：
  数据层 `data/panel/index_flow_series_880008.json`（生产脚本 `夏天-activity\工具\build_index_flow_series.py`，
  L2 `.cah` 88B × `l2_mf` 公式：`0.3×主力买入 + 0.7×主动买入`，507 条、2024-09-30~2026-11-05，约 100KB）。

## 分位与「缺」

- 情绪侧格子：**60 日窗口含当日**，`(严格小于 + 0.5×等于) / 样本数`，与 `emotion/engine.pct_rank` 同式；
  样本 <5 显示「缺」。本卡只是展示层排序，不参与任何打分。
- 恐慌侧格子：直接用 `/api/panic` 给的 250 日分位，格子里标「250 日」，**不与 60 日混用**。
- 任何取不到的读数显示「缺」，不填 0、不插值。当前实例：恐慌序列库最新落库 2026-10-23，
  10-26~10-28 三个交易日未落库 → 「恐慌广度 昨日」格显示缺（并注明最近 10-23 = 90.6）。

## 三态动作（展示规则，未经回测）

写死在页面上，也写在这里，改一处必改另一处：

1. 情绪 <25 且 恐慌 <25 → **等信号**（冰点共振，等止跌与放量确认）
2. 情绪 <25 → **不加仓**
3. 恐慌 ≥70 → **不加仓**（高位不接力）
4. 25 ≤ 情绪 <55 → **做结构**（只做有承接的结构，不做扩散）
5. 情绪 ≥55 → **做结构**（持股为主，不追高）

参考形态里的「不加仓 / 做结构 / 等信号」三档原样保留，不新增第四种动作。
**这是展示规则，不是回测结论**：只有 58 个交易日，撑不起胜率统计，所以信号→动作表的
「历史胜率 / 次数」格子统一写「样本不足（58 日）」，一个数字都不编。
